⚙ 共同研究ネットワーク（機関）
共同研究の集計: 1論文に複数機関が記載されている場合、それを「共同研究ペア」として集計します（例：A・B・Cの3機関 → A×B, A×C, B×C の3ペア）。各タブの「描画」ボタンで再計算されます。
指定した1機関の共同研究先を、共著件数の多い順に並べます。中心機関の候補は「共同先機関数の多い順」で並んでいます。
各機関の「異なる共同研究先の数」（ユニーク件数）。多いほど多様な機関と組んでいるハブ的存在。
合計共著件数の多い上位ペアについて、年別の共著件数推移を折れ線で表示します。
対象機関は「共同研究の幅（ユニーク共同先数）」上位N。色が濃い＝共著件数が多い。スクロール可能。※このタブはPNG非対応（HTMLヒートマップのため）。CSVで全件取得できます。
¥ 資金分析（Funding Intelligence）
資金情報の集計: OpenAlex に含まれる grants / funders / awards 相当の情報を中心に、資金提供機関・助成番号・年次推移・機関との関係を可視化します。 Crossref と NIH RePORTER は登録不要の公開APIとして、必要な範囲だけ手動で補完できます。APIキー入力欄はありません。

OpenAlex由来の資金提供機関に、Crossref / NIH RePORTER で補完した情報も統合して集計します。複数資金源がある論文は各資金源にフルカウントします。
論文数の多い資金源について、年別の支援論文件数を折れ線で表示します。クリックすると、その資金源×年の論文一覧を確認できます。
助成番号・Award ID単位で、コレクション内の成果論文を集計します。KAKENHI番号、NIH grant number などがOpenAlexやCrossrefに入っている場合に有効です。
資金提供機関と所属機関の組み合わせを集計します。「どの資金が、どの研究機関の論文群に現れているか」を把握できます。
上位資金源 × 上位機関のマトリクスです。色が濃いほど、その資金源と機関の組み合わせで現れる論文数が多いことを示します。セルをクリックすると該当論文一覧が開きます。
外部補完: 登録不要で利用できる Crossref REST API と NIH RePORTER API だけを使います。大量一括取得ではなく、DOIまたは助成番号がある論文を上限件数まで順番に補完します。外部API側の制限やCORS設定により取得できない場合があります。
ブラウザ直実行のため、小さめの値から確認することを推奨します。
CrossrefはDOIメタデータ中のfunder / awardを補完します。NIH RePORTERはOpenAlex/Crossrefに含まれるNIH型の助成番号からプロジェクト名・機関・年度・金額を補完します。

# Topic分析（Topic Intelligence）
Topic分析: OpenAlex の primary_topic / topics をもとに、研究テーマの規模・年次推移・新興トピック・機関や資金源との関係を分析します。 組み合わせ分析に有効な箇所は、棒グラフに加えてマトリクス（ヒートマップ）でも表示できます。
コレクション内で出現した研究トピックの規模・影響度を比較します。クリックでそのTopicの論文一覧を確認できます。
論文件数の多いTopicについて、年別推移を折れ線で表示します。クリックで該当年×Topicの論文一覧を確認できます。
スコア定義を表示します。
新しさを「直近3年の量」「直前3年からの増分」「直近3年の平均被引用数」で簡易評価します。各要素の重みは上の入力欄で調整できます。
「どの機関が、どのTopicに強いか」を把握するためのペア分析です。
Topicごとに、どの資金源が現れているかを比較します。資金のテーマ偏在を見る入口です。
上位Topic × 年のマトリクスです。色が濃いほど件数が多く、セルをクリックすると該当論文一覧が開きます。
上位Topic × 上位機関のマトリクスです。色が濃いほど件数が多く、セルをクリックすると該当論文一覧が開きます。
上位Topic × 上位資金源のマトリクスです。色が濃いほど件数が多く、セルをクリックすると該当論文一覧が開きます。
N ネットワーク図（共同研究・共著）
ネットワーク分析: 機関どうしの共同研究ネットワーク、および著者どうしの共著ネットワークを描画します。 年範囲・Topic・資金源・最小論文数などでフィルタし、ノードの色は媒介中心性・次数・重み付き次数・論文数・平均被引用数などに切り替えられます。

⇄ 引用ネットワーク（リファレンス）
引用文献分析: 各論文のreferenced_works（引用している論文のID）を集計して、基礎文献の発見・共引用・書誌結合・内部引用ネットワークを可視化します。OpenAlex の引用カバレッジは出版社・分野により不均一なため、参考文献情報が空の論文も含まれる点にご注意ください。
※ A. 引用文献 Top-N と B. 共引用ペア Top-N は描画時にOpenAlex APIへ追加問い合わせを行います（Top-Nのメタデータ取得のため）。
本コレクション内の論文が最も多く引用している外部論文のTop-N。基礎文献・古典の発見に有効。タイトル・年・誌名のメタデータをOpenAlexから追加取得します（数秒）。
「文献A と 文献B が同じ論文に同時に引用された」回数をペアごとに集計。同じ学派・流派に属する論文ペアを発見できます。Top-Nのメタデータ取得のためAPIアクセスが発生します。
コレクション内の「論文A と 論文B が共通して引用している文献の数」。多いほど学術的に近い＝同じ研究コミュニティ・テーマである可能性が高い。
コレクション内の論文同士の引用関係をネットワーク可視化（vis-network力学レイアウト）。矢印元＝引用元、矢印先＝被引用論文。ノードの大きさ＝コレクション内被引用数。色＝出版年（古い=橙、新しい=青）。ノードをホバーで論文情報、クリックで詳細ポップアップ。マウスでドラッグ／ズーム可。

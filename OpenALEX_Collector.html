🔑 OpenAlex APIキー設定
2026年2月13日より、OpenAlex APIの利用にはAPIキーが必須になりました。 従来の mailto（polite pool）方式は廃止されています。キーを設定しない場合は1日あたり約100リクエストのお試し枠のみで動作し、超過すると 403 等のエラーになります。 無料アカウントを作成すれば、1日あたり10万クレジット（約 $1 相当：単一論文取得は無制限／リスト・フィルタ検索 10,000回／全文検索 1,000回／全文DL 100回 など）まで無料で使えます。
※ 上の内訳は操作種別ごとの目安です。本ツールは論文のメタデータのみを取得し、「全文DL」（論文PDF本文のダウンロード）は行いません。そのため「全文DL 100回/日」の枠に当たることはなく、通常の調査は検索・一覧取得の無料枠内で十分まかなえます。

APIキーの取得手順（約30秒・無料）

  1. openalex.org にアクセスし、無料アカウントを作成します（メールアドレスのみ）。
  2. ログイン後、openalex.org/settings/api（Settings → API）を開きます。
  3. 表示された API key をコピーします。
  4. 下の入力欄に貼り付けて 「保存」 をクリックします。
学術研究で上限の引き上げが必要な場合などは support@openalex.org に相談すると、無料で対応してもらえることがあります（OpenAlex公式案内）。
キーは OpenAlex API へのリクエストに api_key パラメータとしてのみ付与されます。
プライバシーと安全性: 入力したキーはこのブラウザの localStorage にのみ保存され、OpenAlex API 以外には送信されません（本ツールは単一HTMLで、独自の解析サーバーを持ちません）。 共用PCでは使用後に「クリア」してください。キーは第三者に共有しないでください。
Q 論文検索
コマンドライン検索式: コマンドライン検索式では、検索条件を #01 / #02 のような番号付きコマンド行として入力し、最後に T=(#01 AND #02) OR #03 の形で結合します。
各コマンド行には TI= / AB= / TA= / TX= / FT= のいずれかを明示します。
キーワードを空欄にして、所属機関フィルタや著者フィルタだけでも検索可能です。
コマンドライン検索式モードでは、各行のフィールド指定とT式で検索範囲・論理式を制御します。標準モードではOpenAlexへ検索語を直接渡します。
(A AND B) near5 C の A/B グループが広がりすぎる偽陽性を抑制します。
OR式をOpenAlex候補検索へ自動分割する最大クエリ数。超過時はBoolean式1本に圧縮します。
コマンド定義（1行1条件） 行番号は自動採番されます。

#02
#03
#1 と #01 は同じ行として扱います。1行だけ入力してT式が空欄の場合は、自動的に T=(#01) として扱います。
コマンドラインモードでは、詳細フィルタの「検索範囲」はグレーアウトされ、クリックできません。検索範囲は各行の TI= / AB= / TA= / TX= / FT= で指定してください。

名寄せワークベンチ

KW 技術キーワード・AI注釈
操作の流れ: ①技術キーワードを確認 → ②目的別プロンプトを生成して外部AIへ貼付 → ③AIのTSV結果を貼り戻し → ④読むべき論文、技術系譜、総仕上げプロンプト、CSVへ反映します。 このツールはAI APIを呼び出さず、プロンプト生成と貼り戻し管理だけを行います。
技術キーワード抽出: タイトル・要約から1〜N語フレーズを抽出し、TF-IDF = TF × (log((文書数+1)/(出現文書数+1)) + 1)で重み付けします。 冠詞、前置詞、接続詞、代名詞、助動詞、論文メタ語、研究一般語、汎用形容詞、単位表現を拡張ストップワードで除外します。追加ストップワードも指定できます。
検索語そのもの、分野内で常識的すぎる語、表示したくない語を追加すると、技術ポイントが見やすくなります。
再計算するとTF-IDFキーワードが表示されます。

コレクション内の論文同士の引用関係をネットワーク可視化（vis-network力学レイアウト）。矢印元＝引用元、矢印先＝被引用論文。ノードの大きさ＝コレクション内被引用数。色＝出版年（古い=橙、新しい=青）。ノードをホバーで論文情報、クリックで詳細ポップアップ。マウスでドラッグ／ズーム可。
RL 読むべき論文・技術系譜
読書順と系譜: 読むべき論文と技術系譜を同じカードに統合しました。スコア上位だけでなく、技術系譜に入った論文も読むべき候補へ自動追加できます。
文献トリアージ: Topic急増、年齢補正被引用、橋渡し性、技術語新規性、著者・機関シグナル、資金シグナルを使って、読む優先度の高い論文候補を説明可能なスコアで並べます。
候補論文数はスコア上位の件数です。「技術系譜ノードも含める」をONにすると、スコア上位から漏れた系譜上の論文も追加表示します。AI貼り戻し後は、分類・読書順・読む理由もここに表示されます。
スコア再計算すると読むべき論文候補が表示されます。
論文間の系譜: 論文を単に年順に並べるのではなく、内部引用を最優先し、引用関係がない場合はTopic、TF-IDF技術キーワード、共著者・機関の継続性、書誌結合から親子関係を推定して、左から右へ伸びるツリー/DAGとして表示します。 ノードをクリックすると論文詳細、エッジをクリックすると関係理由を表示します。AI技術ポイントを貼り戻すと、全ノードの表示名と説明欄に反映されます。
系譜化ロジック: 親子関係 = 直接引用を最優先。直接引用がない場合のみ、Topic一致、技術キーワードJaccard類似度、共著者/機関の重なり、共通引用文献を使って、過去の論文から最も近い親候補を1つ選びます。 エッジは 先行論文 → 後続論文 です。最小関係スコアを上げると、弱い推定エッジを減らせます。
検索またはCSV読込後に自動表示されます。表示されない場合は「描画」を押してください。

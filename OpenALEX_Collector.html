Q 論文検索
コマンドライン検索式: コマンドライン検索式では、検索条件を #01 / #02 のような番号付きコマンド行として入力し、最後に T=(#01 AND #02) OR #03 の形で結合します。
各コマンド行には TI= / AB= / TA= / TX= / FT= のいずれかを明示します。
キーワードを空欄にして、所属機関フィルタや著者フィルタだけでも検索可能です。
コマンドライン検索式モードでは、各行のフィールド指定とT式で検索範囲・論理式を制御します。標準モードではOpenAlexへ検索語を直接渡します。
(A AND B) near5 C の A/B グループが広がりすぎる偽陽性を抑制します。
OR式をOpenAlex候補検索へ自動分割する最大クエリ数。超過時はBoolean式1本に圧縮します。
コマンド定義（1行1条件） 行番号は自動採番されます。

#02
#03
#1 と #01 は同じ行として扱います。1行だけ入力してT式が空欄の場合は、自動的に T=(#01) として扱います。
コマンドラインモードでは、詳細フィルタの「検索範囲」はグレーアウトされ、クリックできません。検索範囲は各行の TI= / AB= / TA= / TX= / FT= で指定してください。
標準モードでは、入力語をOpenAlexへ直接渡します。詳細フィルタの「検索範囲」が有効です。
コマンドライン検索式の詳細ルール

コマンド行

#01、#02 のように自動採番されます。
各行には1つの検索条件を入力します。
各行には TI= / AB= / TA= / TX= / FT= のいずれかを明示してください。

結合論理式 T

T=(#01 AND #02) OR #03
#1 と #01 は同じ行です。
複数行を使う場合はT式を入力してください。

フィールド

TI=(...) タイトル
AB=(...) 要旨
TA=(...) タイトル＋要旨
TX=(...) OpenAlex総合検索対象（候補取得中心）
FT=(...) OpenAlex fulltext索引（候補取得中心）

検索範囲

コマンドラインモードでは詳細フィルタの「検索範囲」を無効化します。
範囲は各行の TI= / AB= / TA= 等で指定します。
フィールド未指定行は構文エラーです。

Boolean

A AND B 両方を含む
A OR B どちらかを含む
NOT A 除外

近傍・ワイルドカード

A near5 B 順不同で5語以内
A adj3 B AがBより前、3語以内
cathod* / wom?n
例:
#01  TI=(solid adj3 electrolyte)
#02  AB=((degradation AND capacity) near8 (mechanism OR fade*))
#03  TA=(review)
T=(#01 AND #02) AND NOT #03
注意: 内部除外が発生するのは、原則として TI / AB / TA に nearN / adjN を使った場合だけです。通常の TI / AB / TA、Boolean、ワイルドカードではOpenAlex候補をそのまま採用します。TA のnear/adjはタイトル＋要旨を連結した仮想フィールドで判定します。TX / FT はOpenAlex索引による候補取得中心です。
空欄の場合はフィルタなし。セミコロン（;）区切りで複数機関をOR指定できます。OpenAlex機関ID（例: I136199984 / https://openalex.org/I...）も直接指定できます。取得後の分析では「著者・機関名寄せ」によりID/ROR基準で集計します。
空欄の場合はフィルタなし。セミコロン（;）区切りで複数著者を指定すると、すべての著者を含む論文（AND）を抽出します。OpenAlex著者ID（例: A123... / https://openalex.org/A...）も直接指定できます。取得後の分析では「著者・機関名寄せ」によりAuthor ID/ORCID基準で集計します。

ID 著者・機関名寄せ
名寄せ: 著者はOpenAlex Author ID / ORCID、機関はOpenAlex Institution ID / RORを優先して集計します。下のワークベンチで、キーごとの論文、共著者・共同研究先、Topic、同じ名前の候補を確認しながらクリック操作で統合・分離できます。
機関集計単位
通常は「個別ID」が安全です。親機関寄せではOpenAlex lineageを使いますが、名称が取得できた親IDだけに集約します。名称不明の親IDには寄せず、元の機関名を維持するため、IDだけの「親機関 I...」ノードは作りません。

名寄せワークベンチ

使い方: 対象を「著者」または「機関」に切り替え、行の「詳細・名寄せ」を開いてください。ポップアップ内で論文、共著者/共同研究先、Topic、同じ名前の候補を確認しながら統合できます。「分離」はクリックで作成した統合ルールを削除し、OpenAlex ID/RORまたは「名前のみ（IDなし）」の元単位へ戻す操作です。
名前順にすると、同じ著者名・機関名の候補が隣接します。
全件表示は大量データでは描画に時間がかかる場合があります。名前順・絞り込みと併用すると確認しやすくなります。
一括統合では、表示順で最初にチェックされたキーを統合先にします。統合先を明示したい場合は、行の「詳細・名寄せ」を開いて選択してください。

# Topic分析（Topic Intelligence）
Topic分析: OpenAlex の primary_topic / topics をもとに、研究テーマの規模・年次推移・新興トピック・機関・著者・資金源との関係を分析します。 組み合わせ分析に有効な箇所は、棒グラフに加えてマトリクス（ヒートマップ）でも表示できます。
コレクション内で出現した研究トピックの規模・影響度を比較します。クリックでそのTopicの論文一覧を確認できます。
論文件数の多いTopicについて、年別推移を折れ線で表示します。クリックで該当年×Topicの論文一覧を確認できます。
スコア定義を表示します。
新しさを「直近3年の量」「直前3年からの増分」「直近3年の平均被引用数」で簡易評価します。各要素の重みは上の入力欄で調整できます。
「どの機関が、どのTopicに強いか」を把握するためのペア分析です。
Topicごとに、どの資金源が現れているかを比較します。資金のテーマ偏在を見る入口です。
上位Topic × 年のマトリクスです。色が濃いほど件数が多く、セルをクリックすると該当論文一覧が開きます。
上位Topic × 上位機関のマトリクスです。色が濃いほど件数が多く、セルをクリックすると該当論文一覧が開きます。
上位著者 × 上位Topicのマトリクスです。色が濃いほど件数が多く、セルをクリックすると該当論文一覧が開きます。著者は名寄せ後の表示単位で集計します。
上位Topic × 上位資金源のマトリクスです。色が濃いほど件数が多く、セルをクリックすると該当論文一覧が開きます。

⇄ 引用ネットワーク（リファレンス）
引用文献分析: 各論文のreferenced_works（引用している論文のID）を集計して、基礎文献の発見・共引用・書誌結合・内部引用ネットワークを可視化します。OpenAlex の引用カバレッジは出版社・分野により不均一なため、参考文献情報が空の論文も含まれる点にご注意ください。
※ A. 引用文献 Top-N と B. 共引用ペア Top-N は描画時にOpenAlex APIへ追加問い合わせを行います（Top-Nのメタデータ取得のため）。
本コレクション内の論文が最も多く引用している外部論文のTop-N。基礎文献・古典の発見に有効。タイトル・年・誌名のメタデータをOpenAlexから追加取得します（数秒）。
「文献A と 文献B が同じ論文に同時に引用された」回数をペアごとに集計。同じ学派・流派に属する論文ペアを発見できます。Top-Nのメタデータ取得のためAPIアクセスが発生します。
コレクション内の「論文A と 論文B が共通して引用している文献の数」。多いほど学術的に近い＝同じ研究コミュニティ・テーマである可能性が高い。
コレクション内の論文同士の引用関係をネットワーク可視化（vis-network力学レイアウト）。矢印元＝引用元、矢印先＝被引用論文。ノードの大きさ＝コレクション内被引用数。色＝出版年（古い=橙、新しい=青）。ノードをホバーで論文情報、クリックで詳細ポップアップ。マウスでドラッグ／ズーム可。

OpenALEX Collector v5.0 は、OpenAlex APIを中心に、学術論文の収集、トピック分析、資金分析、引用分析、共同研究・共著ネットワーク分析をブラウザ上で行うための単一HTMLツールです。サーバーを用意せず、`OpenALEX_Collector.html` をブラウザで開くだけで利用できます。

> すべての論文は、誰かの肩である。

## 概要

**OpenALEX Collector v5.0** は、OpenAlexの論文メタデータを起点に、研究領域の構造を多面的に把握するための分析ツールです。

主に次の問いに答えることを目的にしています。

- その研究領域は伸びているのか。
- どのTopicが増えているのか。
- どの論文、著者、機関、ジャーナルが影響力を持つのか。
- どの機関どうし、どの著者どうしが共同研究・共著しているのか。
- どの資金源・助成番号が、どのTopicや機関に関係しているのか。
- どの文献が基礎文献・共通基盤・内部引用ハブになっているのか。

v5.0では、v4.0の検索・引用・共同研究・資金・Topic・ネットワーク分析に加えて、**コマンドライン検索式**を実装しました。検索条件を `#01`、`#02` のような番号付きコマンド行として定義し、最後に `T=(#01 AND #02) OR #03` のような結合論理式で母集合を作れます。OpenAlexで広めの候補集合を取得し、Collector内部でタイトル・要旨に対するBoolean、ワイルドカード、nearN / adjN近傍判定を行います。

## v5.0の設計方針

| 方針 | 内容 |
|---|---|
| OpenAlex中心 | 論文母集団形成、Topic、引用文献、機関、著者、資金情報はOpenAlexを主軸にします。 |

| CSV再利用 | 取得済みCSVを再読み込みして分析を継続できます。 |

## クイックスタート

```bash
# 1. HTMLファイルをブラウザで開く
open OpenALEX_Collector.html

# 2. コマンド行と結合論理式Tを入力
# 例: TA=((sulfide OR oxide OR polymer) near5 electrolyte)

# 3. 「検索を実行」をクリック

# 4. 結果を確認し、各カードの「描画」ボタンで分析

# 5. 必要に応じてCSV / PNGをダウンロード
```

対応ブラウザは、Chrome、Edge、Firefox、Safariなどのモダンブラウザです。

## 使い方の全体フロー

```text
検索条件を指定
  ↓
OpenAlexから論文集合を取得
  ↓
データテーブルで確認
  ↓

  ↓

  ↓

```

## モジュール詳細

### 1. 検索フォーム

OpenAlex APIに対する検索条件を設定します。キーワードを空欄にして、所属機関や著者だけで検索することもできます。

| 入力項目 | 内容 | 例 |
|---|---|---|
| コマンド行 | 1行1条件。各行に `TI=` / `AB=` / `TA=` / `TX=` / `FT=` を明示 | `#01  TI=(solid adj3 electrolyte)` |
| 結合論理式 T | コマンド行を `#01` / `#02` で参照し、AND / OR / NOTで結合 | `T=(#01 AND #02) OR #03` |
| 所属機関フィルタ | セミコロン区切りで複数機関をOR指定 | `Meijo University; MIT` |
| 著者フィルタ | セミコロン区切りで複数著者をAND指定 | `Akira Yoshino; John Goodenough` |
| 年範囲 | 開始年・終了年 | `2020`〜`2026` |
| 取得上限 | クエリあたり、または年あたりの取得件数 | `200`, `10000` |
| 年別取得 | 年単位に分けて取得し、10,000件超の領域に対応 | ON/OFF |

詳細フィルタでは、論文種別、ソート順、最小引用数、オープンアクセスのみ、要約ありのみ、英語論文のみを指定できます。コマンドライン検索式モードでは、各コマンド行で検索範囲を明示するため、詳細フィルタの「検索範囲」はグレーアウトされ、内部判定には使いません。標準OpenAlex検索モードに切り替えた場合のみ、詳細フィルタの「検索範囲」が入力全体に適用されます。標準OpenAlex検索モードでは、Collector内部近傍フィルタ用の「近傍グループ内の最大幅（語）」と「OR分割上限」は非表示になります。

### 2. データテーブル

取得した論文を一覧表示します。

| 機能 | 内容 |
|---|---|
| 表示カラム | タイトル、年、著者、所属機関、ジャーナル、引用数、DOI |
| ソート | 各カラムヘッダをクリックして昇順・降順を切り替え |
| ページネーション | 50件単位で表示 |
| DOIリンク | DOIがある論文は `doi.org` へリンク |
| CSV出力 | v5.0拡張カラムを含む論文CSVを出力 |

### 3. 件数グラフ

研究領域の量的な推移を確認する基本カードです。

| タブ | 内容 | クリック動作 |
|---|---|---|
| 件数推移（棒グラフ） | 年別論文件数 | 年をクリックして該当年の論文一覧を表示 |
| 件数推移（折れ線） | 全体推移、または著者比較 | 点をクリックして該当論文一覧を表示 |
| 著者ランキング | 論文件数が多い著者 | 著者詳細を表示 |
| 機関ランキング | 論文件数が多い所属機関 | 機関詳細を表示 |

### 4. 引用ランキング

論文件数だけではなく、引用に基づく影響力を確認するカードです。

| タブ | 内容 |
|---|---|
| 被引用論文 Top-N | 個別論文を被引用数でランキング |
| 被引用著者 Top-N | 著者ごとの合計被引用数でランキング |
| 被引用機関 Top-N | 機関ごとの合計被引用数でランキング |
| 被引用ジャーナル Top-N | ジャーナル・venue別に影響力を確認 |
| 件数×平均被引用数 | X=論文件数、Y=平均被引用数、バブル=合計被引用数 |
| h-index Top-N | 本コレクション内で計算したh-index |

h-indexは、OpenAlex全体の著者・機関h-indexではなく、現在の検索集合に含まれる論文だけで計算します。

### 5. 共同研究ネットワーク（機関集計）

所属機関どうしの共同研究関係を集計します。1論文にA、B、Cの3機関が含まれる場合、A×B、A×C、B×Cの3ペアとして数えます。

| タブ | 内容 |
|---|---|
| 共同研究ペア Top-N | 機関ペアを共著論文数でランキング |
| エゴネットワーク | 1つの中心機関を選び、共同研究先を表示 |
| 共同研究の広さ | 各機関のユニーク共同研究先数を表示 |
| ペア時系列 | 上位ペアの年別共著件数を折れ線表示 |
| 共同研究マトリクス | 上位機関×上位機関のヒートマップ |

共同研究マトリクスはHTMLテーブル形式のヒートマップです。PNG保存ではなく、CSV出力で再利用できます。

### 6. 資金分析（Funding Intelligence）

OpenAlexに含まれる `grants` / `funders` / `awards` 相当の情報を中心に、論文集合に紐づく資金源・助成番号・機関との関係を集計します。

| タブ | 内容 | 主な用途 |
|---|---|---|
| A. 資金源ランキング | 資金提供機関ごとの論文件数、合計被引用数、平均被引用数、助成番号数 | 主要資金源の把握 |
| B. 資金源×年 | 主要資金源の支援論文数を年次推移で表示 | 資金源の時系列変化 |
| C. 助成番号ランキング | Award ID / Grant number単位で論文数・引用数を集計 | 重要助成課題の把握 |
| D. 資金源×機関 | 資金源と所属機関のペアを棒グラフで表示 | どの資金がどの機関に関係しているか |
| E. 資金源×機関マトリクス | 資金源を行、機関を列にしたヒートマップ | 資金源と機関の関係を俯瞰 |
| F. 外部補完 | Crossref / NIH RePORTERで資金情報を補完 | DOI・NIH助成番号の追加情報取得 |

#### 資金源×機関マトリクス

v5.0では、資金源×機関を棒グラフだけでなくマトリクスでも見られます。

- 行：資金源
- 列：所属機関
- セル値：該当する論文件数
- 色：件数が多いほど濃い青
- セルクリック：該当する資金源×機関の論文一覧を表示
- CSV出力：マトリクス形式で出力

#### 外部補完

外部補完は、登録不要で利用できるAPIだけを対象にしています。

| API | 使い方 |
|---|---|
| Crossref REST API | DOIをキーにfunder / award metadataを補完 |
| NIH RePORTER API | NIH型助成番号からプロジェクト番号、年度、金額、PI、機関、課題名を補完 |

KAKEN / JST / AMEDのAPI直結は、登録不要APIのみというv5.0の条件に合わせ、標準機能には入れていません。

### 7. Topic分析（Topic Intelligence）

OpenAlexの `primary_topic` / `topics` を用いて、研究テーマの構造と変化を分析します。

| タブ | 内容 | 主な用途 |
|---|---|---|
| A. Topicランキング | Topicごとの論文件数、合計被引用数、平均被引用数 | 主要テーマの把握 |
| B. Topic×年 | 上位Topicの年次推移を折れ線表示 | テーマの成長・停滞を確認 |
| C. 新興Topic候補 | 直近3年件数、増分、平均被引用数で簡易スコア化 | 伸びているテーマの探索 |
| D. Topic×機関 | Topicと所属機関のペアを棒グラフ表示 | 機関ごとの得意テーマ把握 |
| E. Topic×資金源 | Topicと資金源のペアを棒グラフ表示 | 資金が向かうテーマの把握 |
| F. Topic×年マトリクス | Topicを行、年を列にしたヒートマップ | テーマ推移の俯瞰 |
| G. Topic×機関マトリクス | Topicを行、機関を列にしたヒートマップ | テーマとプレイヤーの対応 |
| H. Topic×資金源マトリクス | Topicを行、資金源を列にしたヒートマップ | テーマと資金配分の対応 |

マトリクスのセルをクリックすると、該当するTopic×年、Topic×機関、Topic×資金源の論文一覧が開きます。

### 8. ネットワーク図（共同研究・共著）

vis-networkを使って、機関ネットワークと著者ネットワークを描画します。v5.0では、単なるランキングではなく、ネットワーク構造を視覚的に探索できます。

| タブ | 内容 |
|---|---|
| A. 機関ネットワーク | 所属機関どうしの共同研究ネットワーク |
| B. 著者ネットワーク | 著者どうしの共著ネットワーク |

#### フィルタ条件

| フィルタ | 内容 |
|---|---|
| ノード数 | 表示対象にする上位ノード数 |
| 最小エッジ重み | 何件以上の共同研究・共著があるエッジを表示するか |
| 最小論文数 | ノードとして表示する著者・機関の最小論文件数 |
| 最小平均被引用 | ノードとして表示する著者・機関の最小平均被引用数 |
| 開始年・終了年 | ネットワーク作成に使う論文の年範囲 |
| Topicフィルタ | Topic名に指定文字列を含む論文だけに絞り込み |
| 資金源フィルタ | 資金源名に指定文字列を含む論文だけに絞り込み |

#### ノードサイズ・ノード色

ノードサイズとノード色は、それぞれ以下の指標に切り替えられます。

- 媒介中心性
- 次数
- 重み付き次数
- 論文数
- 平均被引用数

ノードをクリックすると、その著者・機関の詳細が表示されます。エッジをクリックすると、そのペアの共著論文・共同研究論文が表示されます。

### 9. 引用ネットワーク（リファレンス）

各論文の `referenced_works` を用いて、引用文献の構造を分析します。

| タブ | 内容 | 主な用途 |
|---|---|---|
| A. 引用文献 Top-N | コレクション内論文が多く引用している外部論文 | 基礎文献・古典の発見 |
| B. 共引用ペア Top-N | 同一論文内で同時に引用される文献ペア | 学派・理論枠組みの発見 |
| C. 書誌結合 Top-N | 共通参考文献が多いコレクション内論文ペア | 近接テーマの発見 |
| D. 内部引用ネットワーク | コレクション内の論文同士の引用関係 | 研究領域内の知識流れ把握 |

内部引用ネットワークでは、矢印元が引用元、矢印先が被引用論文です。ノードをクリックすると、論文詳細とコレクション内の引用先・被引用元が表示されます。

### 10. 詳細ポップアップ

グラフのバー、散布図の点、マトリクスのセル、ネットワークのノード・エッジをクリックすると、詳細ポップアップが開きます。

関連論文一覧では、以下の情報を表示します。

- タイトル
- 出版年
- 被引用数
- DOIリンク
- 著者名
- 所属機関
- Topic

ポップアップ内にはコピー用サマリも含まれており、レポートやメモに貼り付けやすい形式で出力できます。

### 11. エクスポート・インポート

| 機能 | 内容 |
|---|---|
| 論文CSV出力 | 取得した論文データをv5.0拡張カラムつきで出力 |
| グラフCSV出力 | 表示Top-Nだけでなく、原則として全件をCSV出力 |
| マトリクスCSV出力 | Topic×年、Topic×機関、Topic×資金源、資金源×機関などを表形式で出力 |
| ネットワークCSV出力 | 機関・著者ネットワークのノードCSV、エッジCSVを出力 |
| PNG出力 | Chart.jsで描画したグラフをPNG保存 |
| CSVアップロード | 過去に保存したCSVを読み込み、再検索せずに分析を再開 |

HTMLテーブル形式のマトリクスやvis-networkのネットワーク図は、PNG出力ではなくCSV出力を基本とします。

## Topicスコアの定義

新興Topic候補では、検索集合内の年次データを使って簡易スコアを計算します。

```text
Score =
  w_recent   × 直近3年の件数
+ w_delta    ×（直近3年の件数 − 直前3年の件数）
+ w_citation × 直近3年の平均被引用数
```

初期値は以下です。

| 重み | 初期値 | 意味 |
|---|---:|---|
| `w_recent` | 1.0 | 直近3年の量を重視する度合い |
| `w_delta` | 1.0 | 直前3年からの増加分を重視する度合い |
| `w_citation` | 1.0 | 直近論文の引用インパクトを重視する度合い |

直近3年・直前3年は、検索集合内の最大出版年を基準に自動設定されます。

```text
最大出版年 = Y
直近3年   = Y-2, Y-1, Y
直前3年   = Y-5, Y-4, Y-3
```

このスコアは探索用の相対指標です。分野横断の絶対評価ではなく、同じ検索集合内で注目Topic候補を並べ替えるために使ってください。

## ネットワーク指標の定義

| 指標 | 定義 | 解釈 |
|---|---|---|
| 次数 | ノードが接続している相手ノード数 | 共同研究先・共著者の多さ |
| 重み付き次数 | 接続エッジの重み合計 | 共同研究・共著の総量 |
| 媒介中心性 | 最短経路上にどれだけ現れるか | クラスター間をつなぐブローカー性 |
| 論文数 | 該当ノードが関係する論文件数 | 生産量 |
| 平均被引用数 | 該当ノードの論文の平均被引用数 | 影響度・質の目安 |

媒介中心性は、複数の研究コミュニティを橋渡しする著者・機関を見つけるのに有効です。

## 検索構文

### 検索モード

| モード | 内容 |
|---|---|
| コマンドライン検索式 | `#01`、`#02` のような番号付きコマンド行を定義し、最後に `T=(#01 AND #02) OR #03` の形式で結合します。OpenAlexで候補集合を取得し、Collector内部でTI/AB/TAを厳密判定します。 |
| 標準OpenAlex検索 | 入力した検索語をOpenAlexへ直接渡します。 |

### コマンドライン検索式の基本形

```text
#01  TI=(solid adj3 electrolyte)
#02  AB=((degradation AND capacity) near8 (mechanism OR fade*))
#03  TA=(review)
T=(#01 AND #02) AND NOT #03
```

各コマンド行は1つの検索条件です。行番号はUIで自動採番されます。`#1` と `#01` は同じ行として扱います。複数行を使う場合は、結合論理式 `T` を入力してください。1行だけ入力し、T式を空欄にした場合は自動的に `T=(#01)` として扱います。

### フィールド

| フィールド | 対象 | 内部厳密判定 |
|---|---|---:|
| `TI` | タイトル | 対応 |
| `AB` | 要旨 | 対応 |
| `TA` | タイトル＋要旨 | 対応。near/adjはタイトルと要旨をまたがず、それぞれの中で判定 |
| `TX` | OpenAlex総合検索対象 | 候補取得中心 |
| `FT` | OpenAlex fulltext索引 | 候補取得中心 |

コマンドライン検索式モードでは、各コマンド行に `TI=` / `AB=` / `TA=` / `TX=` / `FT=` のいずれかを明示してください。フィールド未指定行は構文エラーです。

### 詳細フィルタ「検索範囲」の扱い

コマンドライン検索式モードでは、詳細フィルタの「検索範囲」はグレーアウトされ、クリックできません。検索範囲は各コマンド行の `TI=` / `AB=` / `TA=` / `TX=` / `FT=` で指定します。

| 状態 | 詳細フィルタ「検索範囲」の扱い |
|---|---|
| コマンドライン検索式モード | 無効。各コマンド行のフィールド指定を使用 |
| 標準OpenAlex検索モード | 有効。入力した検索語全体へ適用。「近傍グループ内の最大幅（語）」と「OR分割上限」は非表示 |

OpenAlex候補形成では、式中フィールドが1種類ならそのスコープを使います。`TI` / `AB` / `TA` が複数混在する場合は `title_and_abstract` 相当で候補形成し、その後Collector内部で各フィールド条件を厳密判定します。`TX` / `FT` が混在する場合は、より広めの候補形成を行います。

### Boolean

```text
A AND B
A OR B
NOT A
```

演算子は大文字推奨です。小文字でも解釈します。

### 近傍検索

```text
A near5 B
A adj3 B
```

| 演算子 | 意味 |
|---|---|
| `nearN` | 順不同でN語以内 |
| `adjN` | 左の語句が右の語句より前にあり、N語以内 |

左右には、単語、フレーズ、ワイルドカード、Booleanグループを指定できます。

```text
TA=((sulfide OR oxide OR polymer) near5 electrolyte)
AB=((degradation AND capacity) near8 (mechanism OR fade*))
```

### フレーズ・ワイルドカード

```text
"solid electrolyte"
cathod*
wom?n
```

| 記法 | 意味 |
|---|---|
| `"..."` | 連続フレーズ |
| `*` | 0文字以上に一致 |
| `?` | 1文字に一致 |

語頭ワイルドカード、たとえば `*electrolyte` は使えません。引用符フレーズ内のワイルドカードは未対応です。

### OpenAlex候補取得と内部フィルタ

コマンドライン検索式は、そのままOpenAlexへ投げません。まず近傍条件を広めのBoolean候補式に変換してOpenAlexから候補を取得し、その後Collector内部でTI/AB/TAを判定します。UIの「構文チェック / OpenAlex候補式プレビュー」では、コマンド行、T式、展開後Collector式、OpenAlex候補検索式、候補取得scopeを確認できます。

## ユースケース別ガイド

### 伸びているサブテーマを見つけたい

1. 対象分野を検索します。
2. **Topic分析 → Topic×年** で主要Topicの推移を確認します。
3. **Topic分析 → 新興Topic候補** で直近成長と引用インパクトを見ます。
4. 必要に応じて重みを調整し、量重視・増分重視・引用重視のランキングを比較します。
5. 気になるTopicをクリックし、関連論文・著者・機関を確認します。

### 資金源がどのテーマを押しているか見たい

1. 対象分野を検索します。
2. 必要に応じて **資金分析 → 外部補完** を実行します。
3. **Topic分析 → Topic×資金源** または **Topic×資金源マトリクス** を確認します。
4. **資金分析 → 資金源×機関マトリクス** で、資金源と主要機関の関係を確認します。

### 共同研究・共著のハブを見つけたい

1. 対象分野を検索します。
2. **ネットワーク図 → 機関ネットワーク** または **著者ネットワーク** を開きます。
3. ノード色を **媒介中心性** に設定します。
4. 必要に応じてTopic、資金源、年範囲で絞り込みます。
5. 赤寄りで大きいノードをクリックし、関連論文を確認します。

### 基礎文献や研究流派を見つけたい

1. 対象分野を検索します。
2. **引用ネットワーク → 引用文献 Top-N** で多く引用される外部文献を確認します。
3. **共引用ペア Top-N** で、同じ論文内で一緒に引用される文献ペアを見ます。
4. **書誌結合 Top-N** で、コレクション内で近い論文ペアを確認します。

### 企業・大学・研究機関の強いテーマを比較したい

1. 対象分野を検索します。
2. **Topic分析 → Topic×機関** で上位ペアを確認します。
3. **Topic×機関マトリクス** でテーマと機関の分布を俯瞰します。
4. **引用ランキング → 件数×平均被引用数** で量と質を比較します。

## 注意事項

- Topic分析はOpenAlexの `primary_topic` / `topics` に依存します。Topic情報がない論文はTopic集計から外れます。
- 資金分析はOpenAlexの資金情報を主軸にします。資金情報が空欄でも、実際に資金提供が存在しないことを意味するとは限りません。
- Crossref補完はDOI単位で順次取得します。大量一括取得には向きません。
- NIH RePORTER補完はNIH型助成番号が見つかった場合に有効です。
- KAKEN / JST / AMEDのAPI直結はv5.0では標準搭載していません。
- 新興Topicスコアは探索用の相対指標です。分野横断の絶対比較には使わないでください。
- ネットワーク図の媒介中心性は、現在の検索集合・フィルタ条件内で計算されます。
- h-indexは現在の検索集合内で計算される簡易指標です。
- OpenAlexの引用文献情報は出版社・分野によってカバレッジが異なります。
- vis-networkとChart.jsはCDNから読み込まれます。オフライン環境ではグラフ描画ができない場合があります。
- ブラウザで直接APIを叩くため、外部API側のCORS設定やレート制限により補完が失敗する場合があります。

## トラブルシューティング

| 症状 | 主な原因 | 対応 |
|---|---|---|
| 検索結果が少ない | 要約ありのみ、英語のみ、最小引用数、Collector内部近傍フィルタなどで絞り込み過ぎ | 詳細フィルタを緩める。コマンドライン検索式モードではnearNの距離や近傍グループ最大幅を調整する |
| Collector構文エラーが出る | 括弧・引用符の閉じ忘れ、語頭ワイルドカード、引用符内ワイルドカード | 「構文チェック / OpenAlex候補式プレビュー」でエラー箇所を確認する |
| Topic分析にデータが出ない | OpenAlex側にTopic情報がない、またはCSVにTopic列がない | 新規検索するか、v5.0 CSVを使用 |
| 資金分析にデータが出ない | 論文に資金情報が付与されていない | Crossref補完を試す。NIH型番号があればNIH補完も実行 |
| ネットワーク図が空になる | 最小エッジ重み、最小論文数、Topic/資金源フィルタが厳しすぎる | 閾値を下げ、フィルタを空欄にする |
| マトリクスが見づらい | 対象行・列が多すぎる | 対象Topic数、資金源数、機関数を小さくする |
| PNG出力できない | HTMLテーブル型マトリクスやvis-networkはPNG非対応 | CSV出力を使う |
| 外部補完が失敗する | CORS、レート制限、API応答不安定 | 上限件数を下げ、時間を置いて再実行 |

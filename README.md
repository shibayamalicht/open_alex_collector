## 概要

**OpenALEX Collector v3.0** は、[OpenAlex API](https://openalex.org/) を使って学術論文を検索・収集し、件数推移・引用ランキング・共同研究ネットワーク・引用文献ネットワークを可視化するWebツールです。

- **単一HTMLファイル** — `OpenALEX_Collector.html` をブラウザで開くだけ
- **サーバー不要** — 完全クライアントサイド動作
- **共有が簡単** — ファイル1つを送るだけで誰でも利用可能
- **インタラクティブ** — どのグラフも、バー／点／ノードをクリックすると詳細ポップアップ（コピペ可）

## v1からの主な追加機能

| 機能 | 説明 |
|------|------|
| 著者AND検索 | 著者名のセミコロン区切り入力で複数著者の共著論文だけを抽出 |
| 単独検索対応 | キーワード／所属機関／著者のいずれか1つでも検索可能 |
| 検索範囲フィルタ | 全文 / タイトル＋要約 / タイトルのみ / 要約のみ / fulltextのみ から選択（v2.1） |
| 要約あり / 英語のみフィルタ | NLP・トピックモデル前処理での品質確保（デフォルトON） |
| 引用ランキング 6種 | 被引用論文・著者・機関・ジャーナル Top-N、件数×平均被引用 散布図、h-index |
| 共同研究ネットワーク 5種 | ペアランキング、エゴネットワーク、共同研究の広さ、ペア時系列、ヒートマップ |
| **引用文献ネットワーク 4種**（v3.0で追加） | 引用文献Top-N、共引用ペア、書誌結合、内部引用ネットワーク（vis-network力学レイアウト） |
| **詳細ポップアップ機能**（v3.0で追加） | 全グラフのバー・点・ノードをクリック → 詳細モーダル＋コピー用サマリ |
| `referenced_works` のCSV出力 | 各論文が引用している文献IDの一覧をCSV列に追加 |
| グラフ別CSV出力 | 表示Top-N外も含む全件をCSV出力（Excelで再描画・追加分析） |
| HTMLタグ除去 | `<i>`, `<jats:p>` 等のJATS残骸を自動除去 |
| 言語メタデータ | `language`（OpenAlex判定）と `title_script`（タイトル文字種）の2カラム |

## クイックスタート

```bash
# 1. ファイルをブラウザで開く
open OpenALEX_Collector.html

# 2. 検索キーワードを入力（例: "lithium-ion battery"）
# 3. 「検索を実行」をクリック
# 4. 結果を確認・各カードで可視化
# 5. 必要に応じてCSVダウンロード
```

対応ブラウザ：Chrome / Edge / Firefox / Safari（モダンブラウザ全般）。

## 使い方の全体フロー

```
┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
│  ① 検索フォーム  │ → │  ② データテーブル │ → │  ③〜⑥ グラフ可視化 │
│  キーワード/著者 │   │  論文一覧の確認  │   │  4カード×多タブ  │
│  所属機関 etc.   │   │  ソート・閲覧    │   │  クリックで詳細  │
└──────────────────┘   └──────────────────┘   └──────────────────┘
                                                       ↓
                                              ┌──────────────────┐
                                              │ ⑦ ポップアップ    │
                                              │ 詳細表示・コピペ  │
                                              └──────────────────┘
                                                       ↓
                                              ┌──────────────────┐
                                              │ ⑧ エクスポート   │
                                              │ CSV / PNG        │
                                              └──────────────────┘
```

### ステップ1：検索を実行

1. **検索キーワード**を入力（複数行でOR検索）。空欄でも所属機関・著者で検索可能
2. 必要に応じて**所属機関フィルタ**（例：`Meijo University; The University of Texas at Austin`）と**著者フィルタ**（例：`Akira Yoshino; John Goodenough`）を入力
3. **年範囲**と**取得上限**を設定
4. 詳細フィルタで論文種別・最小引用数・OAのみ・要約ありのみ・英語のみ・検索範囲を設定
5. 「検索を実行」をクリック

### ステップ2：結果を確認

- 上部メトリクス（取得件数 / 要約あり件数 / 期間 / CAGR / トレンド）を確認
- データテーブルで論文一覧をソート・閲覧
- 4つのグラフカード（件数 / 引用 / 共同研究 / 引用ネットワーク）が下に表示される

### ステップ3：グラフでインタラクティブに探索

- 各タブの「描画」ボタンで再計算
- バー／点／ノードを**クリック**すると詳細ポップアップが開く
- ポップアップ内のテキストは全て選択可能、コピーボタンで一括コピー

### ステップ4：エクスポート

- 各グラフの「CSVダウンロード」で**全件**を保存（表示Top-N外も含む）
- 各グラフの「PNGダウンロード」で画像保存（一部は除く）
- 「CSVダウンロード」（論文データセクション）で論文一覧を保存

## モジュール詳細

### ① 検索フォーム

OpenAlex APIに対する検索クエリを構築します。**キーワード／所属機関／著者**の3つの軸＋詳細フィルタを組み合わせて使います。

#### 主入力欄

| 入力欄 | 役割 | 例 |
|--------|------|-----|
| 検索キーワード | スペース=AND、引用符=フレーズ、複数行=OR | `"lithium-ion battery"` |
| 所属機関フィルタ | セミコロン区切りでOR（複数機関どれか） | `Meijo University; MIT` |
| 著者フィルタ | セミコロン区切りでAND（全著者の共著） | `Akira Yoshino; John Goodenough` |
| 年範囲 | 開始年〜終了年 | 2020 〜 2024 |
| 取得上限 | クエリあたり最大何件まで取得 | 200 |
| 年別取得 | ON時は年毎に検索（10,000件/クエリ上限を回避） | チェックボックス |

> **単独検索対応**：キーワードが空欄でも、所属機関や著者だけで検索可能です（v2.1）。

#### 詳細フィルタ

| フィルタ | 説明 | デフォルト |
|----------|------|----------|
| 論文種別 | Article / Review / Book Chapter / Preprint 等（チップ複数選択） | 全選択解除＝全種別 |
| 検索範囲 | 全文 / タイトル＋要約 / タイトルのみ / 要約のみ / fulltextのみ | 全文 |
| ソート順 | 関連度 / 引用数 / 新しい順 / 古い順 | 関連度 |
| 最小引用数 | 指定数以上の引用がある論文のみ取得 | 0 |
| オープンアクセスのみ | OA論文だけに絞り込み | OFF |
| 要約ありのみ | OpenAlex `has_abstract:true` フィルタを適用 | **ON** |
| 英語論文のみ | `language:en` + タイトルCJK等の後フィルタ | **ON** |

#### 解決ロジック

- 所属機関・著者の入力は OpenAlex Institutions / Authors API で自動的にIDに解決
- 同名異人がいる場合は**最も引用数の多い著者を自動採用**（解決後の名前はステータスバーに表示されるので要確認）

### ② データテーブル

検索結果の論文一覧を表示。

| 機能 | 説明 |
|------|------|
| カラム | タイトル / 年 / 著者 / 所属機関 / ジャーナル / 引用数 / DOI |
| ソート | 各カラムヘッダクリックでソート（昇順 / 降順） |
| ページネーション | 50件/ページ |
| DOIリンク | DOIをクリックで `doi.org` へジャンプ |
| CSVダウンロード | 全件をCSV出力（BOM付きUTF-8、Excel互換） |

#### CSV出力カラム（v3.0）

`paper_id`, `title`, `abstract`, `year`, `authors`, `institutions`, `venue`, `citation_count`, `publication_date`, `doi`, `language`, `title_script`, `referenced_works_count`, `referenced_works`

- `language`：OpenAlexの作品レベル言語コード（abstract寄り判定、例：`en`, `ja`）
- `title_script`：タイトル文字種を自前検出（`latin`, `cjk`, `cyrillic`, `latin+cjk` 等）
- `referenced_works`：引用している論文IDのセミコロン区切り（v3.0で追加）

### ③ 件数グラフ カード

「どれだけ書かれているか」を可視化する基本カード（4タブ）。

| タブ | 内容 | クリック動作 |
|------|------|----------|
| 件数推移（棒グラフ） | 年別論文件数の棒。CAGR・トレンド（急上昇〜急減少）自動判定 | 年棒 → その年の論文一覧ポップアップ |
| 件数推移（折れ線） | 同じデータの折れ線。「全体推移」と「著者比較（最大5名）」モード切替 | 年点 → その年（または選択著者×年）の論文一覧 |
| 著者ランキング | 論文件数の多い著者をTop-N横棒（5〜50） | 著者バー → 著者詳細（共著者Top10 + 論文Top15） |
| 機関ランキング | 論文件数の多い所属機関をTop-N横棒 | 機関バー → 機関詳細（共同研究先Top10 + 論文Top15） |

#### 解釈のコツ

- **CAGR**（年平均成長率）が正で大きい→分野が伸びている
- **トレンド判定**：「急上昇」「増加傾向」「横ばい」「減少傾向」「急減少」のラベル
- **著者比較**モードで個人の出版ペースを並べると、活動の盛衰が一目瞭然

### ④ 引用ランキング カード

「量」ではなく「**質・影響力**」で並べ替える6タブ。h-indexは本コレクション内の論文・引用数だけで計算（OpenAlex全著作h-indexとは別物）。

| タブ | 内容 | クリック動作 |
|------|------|----------|
| 被引用論文 Top-N | 個別論文を被引用数で横棒ランキング | 論文バー → 論文詳細（要約含む） |
| 被引用著者 Top-N | 著者ごとの合計被引用数（共著者全員にフルカウント） | 著者バー → 著者詳細 |
| 被引用機関 Top-N | 機関ごとの合計被引用数 | 機関バー → 機関詳細 |
| 被引用ジャーナル Top-N | venue別の合計被引用数 | venueバー → ジャーナル詳細 |
| 件数×平均被引用数 散布図 | バブルチャート：X=論文数、Y=平均被引用、サイズ=合計被引用。著者/機関切替＋最小論文数フィルタ＋上位N | バブル → エンティティ詳細 |
| h-index Top-N | コレクション内h-index。著者/機関切替 | バー → エンティティ詳細 |

#### 散布図の見方

- **右上で大きいバブル** = 多産かつ高引用、合計影響力も大 → 分野の重鎮
- **左上で小バブル** = 少産だが高引用 → 切れ味の鋭い少数精鋭
- **右下** = 多産だが平均被引用低 → 大量生産型
- **左下** = 少数発表で平均も低 → 周辺プレイヤー

### ⑤ 共同研究ネットワーク カード

「**誰と組んでいるか**」を機関レベルで可視化する5タブ。1論文に複数機関が記載されている場合を「共同研究ペア」として集計（A・B・Cの3機関 → A×B, A×C, B×C の3ペア）。

| タブ | 内容 | クリック動作 |
|------|------|----------|
| A. 共同研究ペア Top-N | 「機関A × 機関B」のペアを共著件数で横棒ランキング | ペアバー → 両機関の共著論文リスト |
| B. エゴネットワーク | 1機関を選択→その機関の共同研究先を横棒。中心機関の候補は共同先数順 | 共同先バー → 中心×共同先の共著論文リスト |
| C. 共同研究の広さ | 機関ごとの「ユニーク共同先数」。多いほどハブ的存在 | 機関バー → 機関詳細 |
| D. ペア時系列 | 上位ペアの年別共著件数を折れ線で重ね描き | 折れ線の点 → その年・そのペアの共著論文リスト |
| E. 共同研究マトリクス | 上位N機関のN×Nヒートマップ（HTMLテーブル、色濃淡=共著件数） | セル → 両機関の共著論文リスト／行ヘッダ → 機関詳細 |

#### マトリクスの読み方

- **対角線（同機関同士）はグレーアウト**
- **濃い青セル** = 強い共同研究ペア
- **行に対して色が満遍ない機関** = 多くの機関と連携している
- スティッキーヘッダ＋スクロールで大規模N でも閲覧可

### ⑥ 引用ネットワーク（リファレンス）カード

各論文の `referenced_works`（その論文が引用している論文のID）を活用した分析4タブ。基礎文献の発見・学派分析・コミュニティ可視化に有効。

> **注**：A・C は描画時にOpenAlex APIへ追加問い合わせ（Top-Nのメタデータ取得）を行うため、数秒の遅延あり。

| タブ | 内容 | クリック動作 |
|------|------|----------|
| A. 引用文献 Top-N | コレクション内論文が最も多く引用している外部論文。**基礎文献・古典の発見** | バー → 文献詳細＋引用したコレクション内論文リスト |
| B. 共引用ペア Top-N | 「文献A と 文献B が同じ論文に同時引用」回数。**学派・流派の発見** | ペアバー → 両文献詳細＋両方を引用したコレクション論文 |
| C. 書誌結合 Top-N | コレクション内の論文ペアで「共通参考文献の数」が多いものをランキング。**テーマ近接の発見** | ペアバー → 両論文詳細＋共通参考文献リスト |
| D. 内部引用ネットワーク | コレクション内の論文同士の引用関係を vis-network 力学レイアウトで可視化 | ノード → 論文詳細＋コレクション内被引用/引用先論文 |

#### 内部引用ネットワーク（E）の見方

- **ノードサイズ** = コレクション内被引用数（大きい＝よく引用されている＝ハブ的）
- **ノード色** = 出版年（古い=橙、新しい=青のグラデーション）
- **矢印** = 引用方向（矢印元＝引用元、矢印先＝被引用論文）
- **物理シミュレーション常時ON** で自動配置。ドラッグ／ズーム可
- **ホバー**でツールチップ（タイトル・著者・年・誌・被引用数）
- **クリック**で論文詳細ポップアップ＋引用関係リスト

### ⑦ 詳細ポップアップ（モーダル）

v3.0で全グラフに導入された「クリック→詳細表示」機能。

#### 共通仕様

- グラフのバー／点／ノードをクリック → モーダル展開
- **全テキストが選択可能**（コピペ可）
- 末尾に「コピー用サマリ」ブロック（モノスペース表示）＋📋コピーボタン
- DOIリンク・OpenAlexリンクは別タブで開く
- 閉じる：×ボタン、ESCキー、背景クリックのいずれか

#### ポップアップ内容の種類

| 種別 | 表示内容 |
|------|---------|
| 論文詳細（コレクション内） | タイトル、年、誌、著者全リスト、機関、被引用数、DOI、OpenAlexリンク、言語・文字種、引用文献数、要約（先頭600字）、コピー用サマリ |
| 論文詳細（外部リファレンス） | OpenAlex検索結果メタデータ（年、誌、著者、機関、DOI）＋関連リスト |
| エンティティ詳細（著者／機関／誌） | 名前、論文数、合計被引用数、平均被引用、コレクション内h-index、期間、共著者/共同研究先Top10、論文Top15、コピー用サマリ |
| ペア詳細 | 両エンティティ名、ペア固有の指標（共著数 / 共引用回数 / 共通参考文献数）、関連論文Top30、コピー用サマリ |
| 年フィルタ | 該当年の論文一覧（被引用数順、最大50件）＋合計被引用、コピー用サマリ |

### ⑧ エクスポート機能

| 種類 | 内容 |

| 内部引用ネットワーク | from_paper_id, from_paper_title, to_paper_id, to_paper_title, to_in_degree_in_collection |

## 検索構文

```
キーワード検索:    "lithium-ion battery"        → スペース＝AND
フレーズ一致:      "lithium ion battery"        → 引用符で完全一致
OR検索:           "lithium-ion battery"         → 各クエリを個別検索し
                  "lithium ion battery"           重複除去して統合
機関フィルタ:      Meijo University; MIT         → セミコロン＝OR
著者フィルタ:      Akira Yoshino;                → セミコロン＝AND
                  John Goodenough                 （両者共著の論文だけ）
```

## ユースケース別ガイド

### 「ある分野の基礎文献を発見したい」

1. キーワードで検索（例：`"lithium-ion battery" 2020-2024`）
2. **⑥ 引用ネットワーク → A. 引用文献 Top-N** をクリック
3. コレクション内論文が最も引用している外部論文がランキング表示 → 基礎・古典の発見
4. 各バーをクリックで詳細表示、CSV出力で全件取得

### 「研究機関の影響力を比較したい」

1. 該当分野を検索
2. **④ 引用ランキング → 件数×平均被引用数 散布図**（対象=機関）で量×質を一望
3. **h-index Top-N** で総合指標
4. 散布図のバブルをクリックで機関詳細＋共同研究先＋論文一覧

### 「自分の所属機関と協業可能性のある機関を探したい」

1. 該当分野を検索
2. **⑤ 共同研究ネットワーク → B. エゴネットワーク** で自機関を中心に選択
3. 既存の共同研究先がランキング表示
4. **C. 共同研究の広さ** で広く繋がっている機関（ハブ）を確認
5. **E. 共同研究マトリクス** のヒートマップで分野全体の共同研究構造を把握

### 「ある2論文が同じ研究コミュニティに属するか調べたい」

1. **⑥ 引用ネットワーク → C. 書誌結合 Top-N** を実行
2. 共通参考文献の多いペアが上位に表示 → 学術的に近い論文ペアを発見

### 「同じ流派・学派の文献を見つけたい」

1. **⑥ 引用ネットワーク → B. 共引用ペア Top-N** を実行
2. 「同時に引用される文献ペア」が上位 → 同じ理論枠組み・流派に属する可能性

### 「分野の最新動向（誰がどう参入してきたか）を見たい」

1. **⑤ 共同研究ネットワーク → D. ペア時系列** で年別の共著推移
2. **③ 件数グラフ → 著者比較** モードで主要著者の活動推移
3. **⑥ 引用ネットワーク → D. 内部引用ネットワーク** で「最近の論文が古い論文をどう引用しているか」（色の橙→青の流れ）を観察

## 用語集（書誌計量）

| 用語 | 定義 |
|------|------|
| **h-index** | 「h本以上の論文がそれぞれh回以上引用されている」最大のh。量と質の単一指標 |
| **被引用数（cited_by_count）** | その論文が他の論文から引用された回数 |
| **引用文献（referenced_works）** | その論文が引用している論文のリスト |
| **共引用（co-citation）** | 文献Aと文献Bが、同じ第三の論文から同時に引用されること |
| **書誌結合（bibliographic coupling）** | 論文Pと論文Qが、共通の参考文献を持つこと |
| **CAGR** | 年平均成長率（Compound Annual Growth Rate）。出版数の成長を1つの%値で要約 |
| **エゴネットワーク（ego network）** | ある中心ノードと、その直接の隣接ノードだけからなる部分グラフ |
| **fulltext検索** | 論文本文を対象とした検索（OpenAlexはOA論文等の本文を索引化している） |

## 注意事項

- OpenAlex APIは認証不要ですが、大量取得時はレート制限にご注意ください
- 所属機関・著者フィルタは入力名をOpenAlex APIで自動解決するため、部分一致の場合は意図しない機関・著者にマッチすることがあります（同名異人など）。解決後の正規名はステータスバーに表示されるので確認をおすすめします
- 年別取得モードは年数 × ページネーション回数分のAPIコールが発生するため、広い年範囲での大量取得には時間がかかります
- h-indexはOpenAlex本来の全著作h-indexとは異なり、本コレクション内に含まれる論文・引用数のみから計算されます
- 共同研究マトリクス（ヒートマップ）と引用ネットワーク図はHTMLベース/Canvas外のためPNG出力非対応です（CSVは出力可能）
- OpenAlex の `language` フィールドは要約ベース判定のため、`language=en` でもタイトルが多言語の論文が含まれることがあります（CJK等の自動除外フィルタを併用可能）
- 引用文献情報のカバレッジは出版社・分野により不均一です（化学系は強い、人文系は弱い傾向）。一部論文の `referenced_works` が空になることがあります
- 引用文献 Top-N と 共引用ペア Top-N は描画時にOpenAlex APIへ追加問い合わせを行うため、数秒の遅延があります
- 内部引用ネットワークは vis-network ライブラリを CDN から取得します（オフライン環境では描画不可）
